# NNNN: Claim in one line, stated so someone could disagree with it

- **Status:** `verified` | `inferred` | `candidate`
- **Camera / conditions:** sensor, resolution, intrinsics source, mounting height,
  range, scene type
- **Model:** which model consumed the frames, and in which mode (relative / metric)
- **Claim:** two or three sentences. What holds, and roughly how well.
- **Limits:** where the claim stops holding, or was never measured
- **Evidence:** links to code, commits and results (`repo@SHA:path`). Note any that are
  private.
- **Next probe:** the cheapest test that would change this claim
- **Ask-whom:** who to ask about this camera or model (default: the repo owner)
- **Recorded:** YYYY-MM-DD
